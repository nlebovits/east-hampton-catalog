# NYSDEC Freshwater Wetlands

Freshwater wetlands that NYSDEC mapped, as the Town serves them. NYSDEC [classifies](https://dec.ny.gov/nature/waterbodies/wetlands/freshwater-wetlands-program/conserve) wetlands "from Class 1, which provide the most benefits, to Class IV, which provide the fewest benefits". Since January 1, 2025, a revised [6 NYCRR Part 664](https://dec.ny.gov/sites/default/files/2025-03/part664expressterms.pdf) sets jurisdiction. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
