# NYSDEC Tidal Wetlands

Tidal wetlands mapped by NYSDEC, as the Town serves them. The column names refer to 1974. The category codes come from the [NYSDEC tidal wetland categories](https://dec.ny.gov/nature/waterbodies/wetlands/tidal/categories) page. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| OBJECTID | int64 | ArcGIS object ID in the source layer. |
| TWCAT74 | string | 1974 tidal wetland category. IM is Intertidal Marsh. HM is High Marsh or Salt Meadow. FM is Coastal Fresh Marsh. FC is Formerly Connected. SM is Coastal Shoals, Bars and Mudflats. LZ is Littoral Zone. AA is Adjacent Area. DS is Dredged Spoil. HL is a hole area with no tidal wetland, as TW_Desig states. |
| ACREAGE74 | double | Area in acres, as the source records it. |
| TW_Desig | string | The category name, as text. |
| bbox | struct<xmin: double, ymin: double, xmax: double, ymax: double> | Bounding box of the geometry, for spatial filters. |
| geometry | binary | Feature geometry in EPSG:2263 (US survey feet). |
