# National Wetlands Inventory

National Wetlands Inventory (NWI) polygons, clipped by the Town to the Town area. The ATTRIBUTE column is a Cowardin classification code. The [NWI classification codes](https://www.fws.gov/program/national-wetlands-inventory/classification-codes) page decodes it. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| OBJECTID | int64 | ArcGIS object ID in the source layer. |
| ATTRIBUTE | string | Cowardin classification code. The first letter is the system. E is Estuarine, P is Palustrine, M is Marine, L is Lacustrine, and R is Riverine. |
| Acres | double | Area in acres, as the Town computed it. |
| bbox | struct<xmin: double, ymin: double, xmax: double, ymax: double> | Bounding box of the geometry, for spatial filters. |
| geometry | binary | Feature geometry in EPSG:2263 (US survey feet). |
