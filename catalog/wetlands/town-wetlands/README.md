# Town Surveyed Wetlands

Wetland boundaries that surveys flagged in the Town. The Town states: "The wetland boundaries were digitized from surveys which were georeferenced in the GIS ... The layer is limited to the records the Town Planning department has. There may be wetlands that are not mapped on this layer as the Town does not have survey records for them." Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
