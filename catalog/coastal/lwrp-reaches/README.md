# LWRP Reach Boundaries

The geographic reaches of the Town's [Local Waterfront Revitalization Program](https://dos.ny.gov/location/town-east-hampton-local-waterfront-revitalization-program) (LWRP). The LWRP divides the Town's coast into twelve reaches. [Section I](https://docs.dos.ny.gov/opd-lwrp/LWRP/East%20Hampton_T/Original/LWRP/Section%20I.pdf) of the LWRP names them. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
