# Significant Coastal Fish and Wildlife Habitats

Significant Coastal Fish and Wildlife Habitats (SCFWH) in the Town. The [NYS Department of State](https://dos.ny.gov/significant-coastal-fish-wildlife-habitats) designates these habitats and publishes a narrative for each one. [LWRP Section III](https://docs.dos.ny.gov/opd-lwrp/LWRP/East%20Hampton_T/Original/LWRP/Section%20III.pdf) lists sixteen State habitats in the Town and five habitats that the Town designated as locally significant. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| OBJECTID | int64 | ArcGIS object ID in the source layer. |
| NAME | string | State habitat name. A single space for a locally significant habitat. |
| TXT | string | The habitat name without spaces, for example NapeagueBeach. |
| SCFWH | string | State habitat code, for example EH-3. The value is 0 for a locally significant habitat. |
| LOCALLYSIG | string | Name of a locally significant habitat. A single space for a State habitat. |
| Area_Sq_Ft | double | Area in square feet, as the Town computed it. |
| Acres | double | Area in acres, as the Town computed it. |
| bbox | struct<xmin: double, ymin: double, xmax: double, ymax: double> | Bounding box of the geometry, for spatial filters. |
| geometry | binary | Feature geometry in EPSG:2263 (US survey feet). |
