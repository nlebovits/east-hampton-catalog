# Coastal Erosion Overlay District Zones

Shoreline segments of the Coastal Erosion Overlay District, which the Town Code sets out in [§ 255-3-80](https://ecode360.com/10414408) and the sections after it. Each segment carries one of four zones. The zone definitions come from the legend of the Town's [Use District Map](https://ehamptonny.gov/DocumentCenter/View/1427/LegendRevisions-Sheet-PDF). Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| Zone | int16 | Coastal Erosion Overlay District zone. 1 is the ocean littoral zone, mostly free of erosion control structures. 2 is the bay littoral zone, mostly free of erosion control structures. 3 is the bay littoral zone with isolated erosion control structures. 4 is the bay littoral zone with numerous erosion control structures. |
| Object_ID | int64 | A second object ID from the source. Its origin is not published. |
| ZoneSheets | string | Map sheet number, as text. The source does not name the map series. |
| bbox | struct<xmin: double, ymin: double, xmax: double, ymax: double> | Bounding box of the geometry, for spatial filters. |
| geometry | binary | Feature geometry in EPSG:2263 (US survey feet). |
