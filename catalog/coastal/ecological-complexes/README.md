# Ecological Complexes

Boundary lines of ecological complexes. Four of the 11 lines carry a name: Atlantic Double Dunes, Shelter Island Harbor Bays, Gardiners Island, and Montauk. [LWRP Section III](https://docs.dos.ny.gov/opd-lwrp/LWRP/East%20Hampton_T/Original/LWRP/Section%20III.pdf) takes the ecological complexes from a 1991 U.S. Fish and Wildlife Service study. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
