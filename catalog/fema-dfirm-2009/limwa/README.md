# Limit of Moderate Wave Action, 2009

The Limit of Moderate Wave Action (LiMWA) from the 2009 Suffolk County flood map. FEMA describes the LiMWA as "the approximate landward limit of the 1.5 foot breaking wave" ([FEMA IS-727](https://emilms.fema.gov/is_0727/groups/48.html)). The layer covers all of Suffolk County. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
