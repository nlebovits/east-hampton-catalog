## Processing Notes

Extracted from [ArcGIS layer 56](https://eh-gis.ehamptonny.gov/arcgis/rest/services/MapServiceForOpenGov/MapServer/56) of the Town's MapServiceForOpenGov service on 2026-10-15 with `portolan extract arcgis`.
