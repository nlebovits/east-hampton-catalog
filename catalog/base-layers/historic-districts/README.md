# Historic Districts

Four historic districts: Amagansett, Bluff Road, Montauk, and Springs. The Town Code designates historic districts under [Article VII of Chapter 255](https://ecode360.com/10413761). The [Amagansett Historic District guidelines](https://ecode360.com/10416540) are Zoning Appendix A. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
