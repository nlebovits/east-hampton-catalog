# Harbor Protection Overlay District

The Harbor Protection Overlay District (HPOD), 26 polygons. The Town Code sets out the district in [§§ 255-3-70 to 255-3-75](https://ecode360.com/10414408). The original enacting law is [Appendix C](https://dos.ny.gov/town-east-hampton-appendix-c-harbor-protection-overlay-district) of the Town's Local Waterfront Revitalization Program. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
