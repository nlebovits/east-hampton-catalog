# Water Recharge Overlay District

The Water Recharge Overlay District (WROD), which limits clearing to protect groundwater recharge. The Town Code sets out the district in [§ 255-3-60](https://ecode360.com/10414408) and the sections after it. The Town also designated the district as a [Critical Environmental Area](https://extapps.dec.ny.gov/docs/permits_ej_operations_pdf/waterrechargeoverlay.pdf) effective February 12, 1988. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
