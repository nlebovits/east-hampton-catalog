# Critical Environmental Areas

Critical Environmental Areas (CEA) designated under the State Environmental Quality Review Act, in and near the Town. The [NYSDEC CEA program](https://dec.ny.gov/regulatory/permits-licenses/seqr/critical-environmental-areas) lists every CEA in the State. The Peconic Bay and Environs CEA extends west of the Town. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.

## Schema

| Column | Type | Description |

| OBJECTID | int64 | ArcGIS object ID in the source layer. |
| LOCATION | string | Town or area label from the source. |
