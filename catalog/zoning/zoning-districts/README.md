# Zoning Districts

Use districts of the Town, 458 polygons. The Town states: "It was created by combining the parcel boundaries within a region demarcated by the zoning lines ... This is not the official zoning for the Town ... The Towns legal zoning is represented on the official published maps, as it is directed in the Town Code." The district codes come from [§ 255-2-10](https://ecode360.com/10414303) of the Town Code. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
