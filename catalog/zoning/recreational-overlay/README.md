# Recreational Overlay District

The Recreational Overlay District (ROD), one polygon. Town Code [§ 255-5-50](https://ecode360.com/10414858) lets the Planning Board approve clearing of up to 50% of a lot in this district for a major recreational facility. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
