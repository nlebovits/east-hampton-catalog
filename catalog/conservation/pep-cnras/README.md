# Peconic Estuary Critical Natural Resource Areas

Critical Natural Resource Areas (CNRA) of the [Peconic Estuary Partnership](https://www.peconicestuary.org/). The Partnership's management plan uses CNRAs to protect high quality habitats. The layer covers the whole estuary, not only the Town. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
