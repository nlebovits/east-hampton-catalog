# Trails

Trails, dirt roads, and paths in the Town, 1,108 segments. The Town states that it collected the data from 2012 and that the data "is thus considered DRAFT and constantly evolving". The Town's [Trail Maps](https://www.ehamptonny.gov/532/Trail-Maps) page has the printed trail guides. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.

## Processing Notes
