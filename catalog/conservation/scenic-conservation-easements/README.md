# Scenic and Conservation Easements

Scenic and conservation easements that the Town digitized, 1,410 polygons. The Town's [Community Preservation Fund plan](https://ehamptonny.gov/DocumentCenter/View/1198/The-Community-Preservation-Fund-Project-Plan-PDF) lists scenic and conservation easements among its preservation tools. The layer has no attributes. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.
