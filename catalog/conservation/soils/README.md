# Soils

Soil map units in the Town, from the USDA soil survey of Suffolk County (survey area NY103). The [Web Soil Survey](https://websoilsurvey.nrcs.usda.gov/) has the current map units and their properties. Read [AGENTS.md](AGENTS.md) for the column meanings and tested queries.

## Schema

| Column | Type | Description |
|--------|------|-------------|
| OBJECTID | int64 | ArcGIS object ID in the source layer. |
| MUSYM | string | Soil map unit symbol. For example, BgA is Bridgehampton silt loam, 0 to 2 percent slopes. MkB is Montauk loam, 3 to 8 percent slopes. |
| Acres | double | Area in acres, as the Town computed it. |
| bbox | struct<xmin: double, ymin: double, xmax: double, ymax: double> | Bounding box of the geometry, for spatial filters. |
| geometry | binary | Feature geometry in EPSG:2263 (US survey feet). |

## Known Issues

MfA and MfB are not in the current NY103 soil survey legend. MfB is the second most common symbol in the layer, with 77 polygons. The Town layer can predate the current survey.
