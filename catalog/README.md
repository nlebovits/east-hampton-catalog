A mirror of 38 layers from the Town of East Hampton, New York [MapServiceForOpenGov](https://eh-gis.ehamptonny.gov/arcgis/rest/services/MapServiceForOpenGov/MapServer) ArcGIS service: zoning and overlay districts, wetlands, coastal management areas, FEMA flood zones, trails, and conservation easements. Each layer is a GeoParquet file in the Town's coordinate system (EPSG:2263) with PMTiles for the map. The Town states that the service "contains draft data that may be incomplete". Read the [terms](LICENSE.md) before you use the data, and read [AGENTS.md](AGENTS.md) before you query it.

## Processing Notes

Extracted on 2026-10-15 with `portolan extract arcgis` (portolan-cli 0.8.0). 38 of the service's 53 feature layers are mirrored. The mirror omits the tax parcel layers (EHTaxMap, AHO & LBO, and the parcel-shaped Town property layers 70 to 75) because the Suffolk County Real Property Tax Service Agency holds the parcel linework copyright. It omits Building Footprints and Pool Points because they derive from licensed Pictometry imagery. It omits duplicate layers (81, 37, 80) and layers the Town marks as not georeferenced or draft (49, 50). The `--layers` filter of portolan-cli 0.8.0 matches list positions, not layer IDs ([portolan-cli#1003](https://github.com/portolan-sdi/portolan-cli/issues/1003)), so the extraction passed list positions. Each collection's processing notes name its source layer. Thumbnails render each default style with chiitiler over the Esri World Light Gray Canvas basemap. Basemap sources: Esri, HERE, Garmin, © OpenStreetMap contributors, and the GIS user community.
